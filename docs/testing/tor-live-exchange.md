# Реальный обмен через Tor: 25 ноября 2026

Результат: **PASS**, `TestTorSecureChannelLive` завершился за **63,78 секунды**.
Исправления кода для этого запуска не потребовались.

## Условия

- Проверенный коммит: `d41e265` — merge модуля `tor-connectivity` в `dev`.
- macOS arm64, Go 1.26.3, Tor 0.4.9.16 и отдельный Lyrebird.
- Два независимых Tor-процесса и два процесса Lyrebird на одной машине.
- Режим obfs4, четыре предоставленные пользователем строки мостов в закрытом
  временном конфиге вне репозитория. Проверен набор в целом; успешное подключение
  не означает, что каждый из четырёх мостов доступен по отдельности.
- На запуск каждого узла отведено 5 минут; общий контекст теста — 12 минут,
  внешний лимит `go test` — 15 минут. Настройки доставки обычные, без ускорения
  таймеров и ручного изменения очереди.
- Временные профили и контакты, реальные шифрованные seed-файлы и SQLite,
  тестовое хранилище ключей в памяти. Личные профили и секреты ОС не использовались.

## Что подтвердилось

1. Оба узла завершили bootstrap и опубликовали onion-службы.
2. Сообщение с Unicode прошло Alice → Bob, ответ — Bob → Alice, через настоящий
   Tor и TLS с взаимной проверкой сохранённых ключей.
3. На принимающей стороне сообщение сохранилось; исходящее получило статус
   delivered после ACK. История проверена по ID, тексту, направлению и собеседнику.
4. После остановки Bob новое сообщение Alice осталось pending на диске с записью
   попытки. Затем Alice тоже остановилась; у Bob нового сообщения ещё не было.
5. Оба узла перезапустились с прежними профилями, контактами и onion-адресами.
   Очередь автоматически повторила попытку с прежним ID, без нового `Queue`.
6. Сообщение доставилось без дублей. После закрытия сервисов и повторного открытия
   SQLite история и статусы delivered сохранились. Хранилища освободились,
   временные каталоги Tor/Lyrebird были удалены.

## Повторение

Подготовьте приватный `tor.json` по [руководству](../tor.md#конфигурация-подключения)
с рабочими мостами и путями к Tor/Lyrebird. Из корня репозитория:

```sh
SHADOWTALK_TOR_CONFIG=/absolute/path/to/tor.json \
SHADOWTALK_TOR_LIVE_TEST=1 \
go test ./tests/integration -run '^TestTorSecureChannelLive$' -count=1 -v -timeout=15m
```

`SHADOWTALK_FAKE_TOR` должен отсутствовать. `SHADOWTALK_TOR_BINARY`, если задан,
переопределяет бинарник из JSON. На macOS/Linux нужны права 0600 для конфига;
адреса мостов, сертификаты и сам файл не включаются в отчёт или Git.

## Границы результата

Это автоматическая проверка полного сервиса доставки на одной macOS-машине.
Интерактивный TUI через публичный Tor, обмен между разными компьютерами и
сетевой запуск на Windows/Linux ещё не проверены. Предыдущие PTY-тесты интерфейса
использовали локальные подставные Tor-процессы.

Успех obfs4 не устанавливает причину прежней остановки прямого Tor на 10–14%
и не подтверждает восстановление прямого подключения. Доступность мостов может
измениться. Проверка не заменяет независимый аудит безопасности и не означает
готовность релизных пакетов.
