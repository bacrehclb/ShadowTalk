# Проектирование протокола

Этот файл содержит исходные договорённости. Спецификация сетевого формата
и совместимая реализация пока отсутствуют.

## Знакомство

Предлагаемый формат приглашения — `shadowtalk://invite/v1/…`. Оно содержит
адрес узла, публичный ключ, случайный секрет, срок действия и подпись.
По умолчанию предлагается срок 24 часа и одно использование.

Получатель вставляет приглашение, устанавливает защищённое соединение
и отправляет запрос. Создатель подтверждает контакт. После локального
сохранения контакта приглашение привязывается к его ключу и расходуется.
Повтор запроса тем же ключом после обрыва должен завершать эту же операцию.

## Доставка

Сообщения получают устойчивые идентификаторы. Получатель подтверждает
сохранение сообщения; повторная передача не создаёт повторную запись.
Очередь исходящих сообщений должна переживать перезапуск приложения.

Перед реализацией нужно определить формат кадров, версии, лимиты,
подтверждения, ошибки, процедуру знакомства и правила переподключения.
Исходный кандидат для кодирования — JSON с префиксом длины кадра.
