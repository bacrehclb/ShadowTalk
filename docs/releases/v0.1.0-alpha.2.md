# ShadowTalk v0.1.0-alpha.2 — bundled Tor

Release candidate notes; this version has not been published yet.

## Changes

- Installers and portable archives include Tor Expert Bundle 16.0.3 (Tor
  0.4.9.17), Lyrebird, their runtime libraries and license texts.
- ShadowTalk automatically finds its own Tor runtime after installation or
  relocation. Manual executable paths still take precedence.
- Direct connections need no Tor configuration file. For obfs4, the configuration
  can contain just mode, bridges and an optional timeout; Lyrebird is found
  automatically.
- The universal macOS app includes separate Apple Silicon and Intel Tor runtimes.
- Build downloads are pinned by SHA-256. Help, profile commands and chat startup
  perform no dependency downloads.

## Upgrading

Keep the existing profile and OS credential-store entry. To switch from an
alpha.1 configuration to bundled executables, remove `tor_binary` and
`lyrebird_binary` from `tor.json`, leaving bridge settings in place. No profile
or history migration is introduced. See [bundled Tor](../bundled-tor.md).

## Validation and limitations

Native macOS packaging and offline Tor controller checks are part of preparation.
Windows/Linux installation and native runtime checks must pass on their respective
platforms before publication. Cross-compilation alone does not establish that.
The earlier live Tor exchange report concerns two nodes on one macOS machine;
this release does not claim a completed two-computer test or independent security
audit. Signing remains ad-hoc on macOS; builds have no verified publisher signature.

Working bridges may still be needed on restricted networks. The OS credential
store is still required; Tor bundling does not replace it.
