# ShadowTalk v0.1.0-alpha.1

An experimental peer-to-peer messenger for your terminal, written in Go.
Connections use Tor onion services; there is no shared ShadowTalk chat server.

## Included

- Local profiles with cryptographic identities and OS-protected key storage.
- Signed invitation tokens, contact aliases and explicit fingerprint confirmation.
- Terminal chat with encrypted local history, delivery acknowledgements and a
  persistent outgoing queue that retries after restart.
- One universal macOS DMG with `ShadowTalk.app` for Apple Silicon and Intel.
  The app opens the existing terminal interface; it requires macOS 12+.
- Windows setup EXE for x64 (amd64).
- Linux DEB/RPM packages for arm64 and amd64.
- `THIRD_PARTY_NOTICES.txt` with dependency and Go toolchain license texts,
  included in the packages and available as a separate asset.

## Getting started

Download the file for your operating system and processor and compare its SHA-256
with the attached `checksums.txt`.

- **macOS:** use `shadowtalk_0.1.0-alpha.1_darwin_universal.dmg` on either CPU.
  Open the image, drag **ShadowTalk.app → Applications**, then open the copied app.
  Terminal shows **1 — Профиль**, **2 — Чат**, **3 — Команды**, **0 — Выход**.
  Use **3 — Команды** for the `shadowtalk ...` examples below; the app does not
  add a global command to PATH.
- **Windows x64:** run the setup EXE and open a new terminal after installation.
- **Linux:** install the matching DEB with `apt` or RPM with `dnf`.

See the [current installation guide](https://github.com/bacrehclb/ShadowTalk/blob/main/docs/install.md)
and the [English](https://github.com/bacrehclb/ShadowTalk/blob/main/README.md#usage) /
[Russian](https://github.com/bacrehclb/ShadowTalk/blob/main/README.ru.md#использование)
walkthroughs. These include the later macOS launcher; the original tag's bundled
documentation describes the earlier PKG distribution. The app also includes
`Contents/Resources/App Guide.md`.
Go is not required for packaged builds. Tor, Lyrebird for obfs4, and an accessible
OS credential store are separate requirements. The interface is currently in Russian.

The release has six platform downloads, `checksums.txt` and `THIRD_PARTY_NOTICES.txt`
(eight uploaded files).
Portable archives, standalone PKGs, metadata and the Homebrew recipe remain in
the `shadowtalk-packages` CI artifact. GitHub's **Source code** archives contain
source files, not an installed application.

Create your profile with `shadowtalk ui`, configure Tor, exchange invitations in
both directions and verify fingerprints through a trusted channel. Start the
conversation with `shadowtalk chat`.

## Alpha limitations

- The macOS app has an ad-hoc signature, without Developer ID or Apple
  notarization. Windows installers do not have an Authenticode publisher
  signature. Checksums detect changed files; they are not a publisher signature.
- Real Tor exchange, durable acknowledgements and restart recovery were tested
  with two nodes on one macOS arm64 computer using obfs4. Separate-computer
  exchange, live Windows/Linux networking and interactive chat over real Tor
  remain unverified. See the
  [test report](https://github.com/bacrehclb/ShadowTalk/blob/v0.1.0-alpha.1/docs/testing/tor-live-exchange.md).
- Both peers must eventually be online together. Pending messages stay in the
  sender's local queue; there is no always-online mailbox server.
- This is a terminal application. Desktop GUI, group chats and file transfer
  are not included. Contact changes require restarting the chat.
- Linux arm64 and the other macOS architecture are cross-built. Native RPM
  installation and interactive Windows installer appearance need further checks.
- The profile encryption key depends on the OS credential store. Losing it
  makes the encrypted seed/history inaccessible; do not treat this alpha as a
  backup or recovery solution.
- No independent security audit has been completed. Protocol, storage formats
  and commands may change between alpha versions.
- A public Homebrew tap is not available yet.

## Build provenance

The application core comes from `v0.1.0-alpha.1` at commit
`7548577b3e182e7977dde8aa99c5c8ab3d5f18a5`. The macOS launcher and custom DMG were
prepared separately after that tag. The app retains its payload and packaging
metadata in `Contents/Resources/build.json`; its launcher was built from a
working tree with changes that were subsequently committed as
[`62aac89`](https://github.com/bacrehclb/ShadowTalk/commit/62aac89).

The final DMG's embedded app was compared byte-for-byte with the verified alpha
app, and both CPU slices and ad-hoc signatures were checked. Its terminal menu,
version output, isolated profile screen and return to the shell were exercised
on macOS arm64. The maintainer also reported copying the app to Applications and
opening its menu through the icon; this does not establish live two-device chat.

Please report problems with the output of `shadowtalk --version`, your OS and
the steps to reproduce. Keep private keys, invitation tokens, bridge addresses,
profile files and message contents out of public issues.
