# Назначение ShadowTalk

ShadowTalk проектируется как P2P-мессенджер на Go с удобным терминальным
интерфейсом. Общение проходит через сеть Tor без общего сервера приложения.

## Основные сценарии

- Создать локальный профиль, указав ник; ключи создаёт приложение.
- Создать одноразовое приглашение и передать его собеседнику.
- Добавить контакт по приглашению и подтвердить входящий запрос.
- Общаться с сохранённым контактом без повторной выдачи приглашений.
- Читать локальную историю и продолжать доставку после переподключения.

Ник — отображаемое имя; идентичность определяется ключом. Предложенные правила
ника: 3–24 символа, латинские буквы, цифры, `_` и `-`, буква или цифра по краям.
Глобальная уникальность ника не требуется.

При отсутствии посредника сообщение офлайн-собеседнику остаётся в локальной
очереди отправителя. Для доставки оба узла должны оказаться онлайн.

Комнаты остаются в плане развития. Их включение в первый релиз, правила
участия и доступ к истории пока не определены.
