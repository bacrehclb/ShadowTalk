SHADOWTALK
Terminal conversations over Tor.

Open "Install ShadowTalk.pkg" to install the command into /usr/local/bin.
Then open Terminal and run:

    shadowtalk --version
    shadowtalk ui

Tor and Lyrebird are included. Configure bridges if needed, exchange invitations with your
contact, then run:

    shadowtalk chat

Go is not required. Tor and Lyrebird are selected automatically.
Each device needs its own profile and access to its OS credential store.

Setup instructions:

Development packages are not Developer ID signed or notarized. A successful
build does not establish trust in a downloaded copy. Verify its origin and
SHA-256 checksum before choosing to install it.
